💳 Bank Management System

A simple and user-friendly Bank Management System built with Java Swing and MySQL.
This project makes banking tasks like account creation, deposits, withdrawals, and balance checks easy to manage through a clean desktop interface.

✨ Features
Create new bank accounts
Deposit and withdraw money
Check account balance
View customer details
Update account information
Delete accounts safely
🛠 Tech Stack
Java
Java Swing
MySQL
JDBC
🎯 Project Goal

This project was created to improve practical knowledge of:

Core Java programming
GUI design with Swing
Database connectivity
CRUD operations
🚀 How to Run
Clone this repository
Open the project in NetBeans or Eclipse
Import the MySQL database
Update database username and password in the code
Run the project
